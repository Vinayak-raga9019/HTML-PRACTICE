# HTML Practice & Concepts

A repository containing hands-on exercises, foundational practice files, and experiments covering HTML5 fundamentals and modern semantic web markup.

---

## 📌 Covered Topics

* **HTML Structure & Document Anatomy:** `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`, and meta configurations.
* **Semantic HTML5:** Using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` for clean document outlines.
* **Text Formatting & Typography:** Headings (`<h1>`–`<h6>`), paragraphs, lists (`<ul>`, `<ol>`, `<dl>`), blockquotes, and inline text tags.
* **Links & Media:** Hyperlinks, internal navigation, images (`<img>`), figure captions, and basic media embeds.
* **Tables:** Structured tabular data using `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, and `<td>`.
* **Forms & Validation:** Inputs, form controls, labels, buttons, and native HTML5 attribute validation (`required`, `pattern`, `type`).
